# Risk register

Generated by `zag emit` from `src/ai/risk.zig`. A treatment that claims to
reduce a risk must name a control that is enforced by code; an instruction to
a model is not a control, and the build says so.

Risk register

R-INJECTION  very high -> medium
    Content the agent reads — a file, a web page, a tool result — tells it to do something the person did not ask for.
    Treatment: mitigate by C-POLICY, C-TYPED-TOOLS, C-CONTEXT-SPLIT
R-IRREVERSIBLE  high -> low
    An agent deletes work, or pushes a change, that the person cannot get back.
    Treatment: mitigate by C-APPROVAL, C-POLICY, C-LOG
R-EGRESS  high -> medium
    Workspace content, including secrets in files, leaves the machine in a model request or a network call.
    Treatment: mitigate by C-POLICY, C-APPROVAL, C-LOG
R-WRONG-OUTPUT  high -> high
    The agent writes a change that looks right, passes review, and is wrong.
    Treatment: mitigate by C-PROVENANCE, C-LOG
R-OPACITY  medium -> low
    A person cannot tell what the agent did, or why, after the fact.
    Treatment: mitigate by C-LOG, C-PROVENANCE, C-PLAIN
R-ESCAPE  high -> low
    An agent reaches files outside the workspace it was given.
    Treatment: mitigate by C-PATHS, C-POLICY

Every risk has an owner and a treatment.
